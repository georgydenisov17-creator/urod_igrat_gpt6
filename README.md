# Урод

Небольшая 2D-игра на HTML5 Canvas. Работает как статический сайт в современных мобильных браузерах Android и iOS, а также на компьютере.

## Запуск локально

Откройте `index.html` в современном браузере. Для публикации используйте GitHub Pages.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите `index.html`, `style.css`, `game.js` и `README.md` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Откройте адрес `https://ИМЯ.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

## Как играть

- **ГАЗ** — удерживать для разгона до 50 км/ч.
- **ТОРМОЗ** — удерживать для замедления.
- **ПРЫЖОК** — перепрыгивать ВАЗ-2106. Прыжок рассчитан на преодоление одной машины.
- **ВИЛИ** — удерживать для езды на заднем колесе. Следите за шкалой: при 80° байкер падает.
- Собирайте бутылки «ГАЗЯВА»: они дают очки и валюту для магазина скинов.
- На компьютере: `←` тормоз, `→` газ, `Space` прыжок, `↑` или `W` — вили.

## Особенности

- Пасмурная серо-приглушённая палитра и деревенский фон с домами, гаражами, заборами, берёзами и ЛЭП.
- Все декорации привязаны к общей линии грунта, чтобы не было эффекта парящих построек.
- Анимированные колёса с вращением, подвеска, покачивание и отдельная анимация падения.
- Сенсорное управление через Pointer Events для мобильных браузеров.
- Рекорд, кошелёк и скины сохраняются в `localStorage`.
- Нет внешних библиотек, CDN или этапа сборки.

## Совместимость

Игра предназначена для актуальных версий Safari на iPhone/iPad и Chrome на Android. Для публикации не требуется сервер: достаточно GitHub Pages. Фактическая производительность зависит от модели устройства и браузера.
